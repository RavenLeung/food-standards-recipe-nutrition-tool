# 本地菜谱营养分析工具

使用 FSANZ NPC 营养数据集，在本机浏览器内分析文字菜谱。不会上传食品数据。

## 启动

```bash
npm install
npm start
```

打开 `http://127.0.0.1:4173`。

所需 CSV 已包含在 [`data/`](data/README.md) 目录；也可通过 `NUTRIENT_DATASET` 环境变量指定另一份本地数据集。

## 输入格式

每行一项配料，并写出克数。例如：

```text
鸡胸肉 300g
熟白米饭 400g
西兰花 80g
酱油 25g
```

工具支持一小组常见中文别名，也可直接使用数据集里的英文食品名称。结果会显示实际匹配的 FSANZ 条目；黄色或红色项目必须人工确认。

## 重要限制

这是内部计算和审核工具，不是自动合规批准系统。发布标签前必须核对供应商规格、配方、烹饪后实际重量、食品匹配和过敏原；对于营养/健康宣称或不确定产品，应使用 FSANZ Nutrition Panel Calculator 或请食品标签专业人员复核。
